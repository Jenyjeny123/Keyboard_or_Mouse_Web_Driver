## 🔄 数据流

### 发送流程 (Web → Device)

```
[用户点击]
   │
   ▼
[HTML onclick 事件]
   │
   ▼
[window.functionName()]  ← 桥接 HTML 事件
   │
   ▼
[Service.method()]  ← DeviceService / LightingService / TestService
   │
   ▼
[Protocol.send(cmd, data)]  ← 异步 + 超时
   │
   ▼
[PacketBuilder.build()]  ← 64 字节包
   │
   ▼
[Transport.send()]  ← WebHIDTransport.sendReport()
   │
   ▼
[navigator.hid]  ← 浏览器 API
   │
   ▼
[USB HID]
   │
   ▼
[设备固件]
```

### 接收流程 (Device → Web)

```
[设备响应]
   │
   ▼
[USB HID 中断]
   │
   ▼
[navigator.hid]
   │
   ▼
[inputreport 事件]
   │
   ▼
[WebHIDTransport.onReceive]
   │
   ▼
[Protocol.handleResponse()]
   │
   ▼
[PacketBuilder.parse()]  ← 解析 64 字节
   │
   ▼
[Promise resolve]  ← 匹配的 send() 返回
   │
   ▼
[Service.handleResponse()]
   │
   ▼
[bus.emit()]  ← 事件分发
   │
   ▼
[bus.on() listeners]  ← 多个订阅者
   │
   ▼
[UI 更新 / 日志记录 / Toast]
```

## 🧱 分层职责

| 层级 | 职责 | 依赖 |
|------|------|------|
| **Core** | 基础工具 (事件/日志/配置) | 无 |
| **Transport** | 设备 I/O 抽象 | Core |
| **Protocol** | 数据包构建/解析, 命令管理 | Core |
| **Services** | 业务逻辑 (设备/灯光/测试) | Core, Protocol, Transport |
| **UI** | 可视化组件 | Core, Services |
| **Application** | 页面入口 (HTML + 引导) | 所有 |

         Service.method()

              │           │

              │           ├─► Toast 组件 (toast:shown)
              │           └─► UI 监听器 (DOM 更新)

## 🔐 设计原则

### 1. 单一职责 (SRP)
每个模块只负责一件事:
- `EventBus` 只做事件
- `Logger` 只做日志
- `PacketBuilder` 只做包构建

### 2. 开闭原则 (OCP)
对扩展开放, 对修改关闭:
- 新增命令 → 只需在 `BaseCommands.js` 添加
- 新增服务 → 继承 `Service` 基类
- 新增组件 → 继承 `Component` 基类

### 3. 依赖倒置 (DIP)
高层模块不依赖低层:
- `Service` 依赖 `Protocol` 接口
- `Protocol` 依赖 `Transport` 接口
- 可以注入 Mock 实现

### 4. 接口隔离 (ISP)
接口最小化:
- `WebHIDTransport` 和 `MockTransport` 共享相同接口
- `service` 只需要 transport 的 send/onReceive 能力

## 🛡️ 错误处理

```
错误源                  处理层
─────────────────────────────────
浏览器不支持 WebHID  →  UI 提示 + disable 功能
HID 设备未连接        →  Service 重试 + 状态广播
协议超时              →  Protocol 抛出 + 事件
命令返回错误          →  Service 解析 + 用户提示
协议解析失败          →  Logger 记录 + 跳过
网络/USB 中断         →  Transport 抛出 + 自动重连
```
